## Sobre como funciona o site: 

Este site funciona como um player local de músicas para drift e carros esportivos: você pode carregar faixas diretamente do seu dispositivo ou usar listas pré-selecionadas para tocar durante suas sessões de direção. A reprodução é feita localmente no navegador (sem envio de arquivos para servidores), com controles simples de play/pause, pular faixa e volume. Há também opções para criar e salvar listas de reprodução personalizadas, repetir faixas ou ativar reprodução aleatória.

### Principais recursos:

    Reproduzir músicas locais (arrastar e soltar ou selecionar arquivos).
    Listas pré-selecionadas com faixas temáticas para drift e esportivos.
    Controles: play/pause, próxima/anterior, slider de progresso e controle de volume.
    Modo loop e reprodução aleatória.
    Criar, renomear e excluir playlists locais (armazenadas no navegador).
    Visualizações simples (nome da faixa, artista, capa se disponível).

### Como usar (passos rápidos):

    Clique em "Adicionar faixas" ou arraste arquivos de áudio para a área de reprodução.
    Selecione uma playlist existente ou crie uma nova.
    Use os controles para reproduzir, pausar, pular e ajustar volume.
    Para repetir ou embaralhar, ative os botões correspondentes na barra de reprodução.
    Playlists criadas ficam salvas localmente no seu navegador para uso futuro.

Nota de privacidade: o áudio e as playlists são processados localmente pelo navegador; nenhum arquivo é enviado a servidores externos.
